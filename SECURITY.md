# Security Policy

## Supported versions

Security fixes are applied to the latest commit on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately to the repository owner through GitHub's private vulnerability-reporting feature, if enabled, or via the contact information on the owner's GitHub profile. Include reproduction steps, potential impact, and any suggested remediation.

This educational repository does not accept real maintenance, operational, personal, customer, or credential data in reports, issues, examples, or pull requests.

## Scope and safety

This project is a synthetic demonstration only. It does not provide a production maintenance system, safety control, or decision-support service. Do not deploy it against real equipment without an independent security, safety, privacy, and governance review.
